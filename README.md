# TideSway

TideSway is a distributed data analytics platform enabling real-time advanced analytics through a scalable Optimizer and robust Analyzer.

TideSway is aimed at developers who need a straightforward, dependable solution.

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/TideSway.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

TideSway is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
